# De Pátria para Pátria

## Descrição do Projeto

Uma página web responsiva que apresenta a exposição "De Pátria para Pátria" da Galeria de Arte TripleTen. O projeto mostra as cidades natais de funcionários da TripleTen através de um layout adaptativo que funciona perfeitamente em diferentes dispositivos.

## Funcionalidades

- Design responsivo para desktop, tablet e mobile
- Layout adaptativo que se ajusta a diferentes tamanhos de tela
- Galeria de imagens das cidades apresentadas
- Interface moderna e acessível

## Tecnologias Utilizadas

- HTML5 semântico
- CSS3 com Flexbox e Grid
- Media Queries para responsividade
- Metodologia BEM para organização do CSS
- Figma para especificações de design
